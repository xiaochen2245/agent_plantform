# Design System: Agent 平台 · 企业内部 AI 门户
**Project ID:** projects/18205192342207537492

## 1. Visual Theme & Atmosphere

沉稳、克制、值得信赖的企业级 AI 工作台。整体气质是"安静的智能"——大面积留白与低饱和背景衬托一个鲜明的青色主色，让对话内容成为视觉主角。无花哨装饰、无渐变堆砌；层级靠字重与hairline描边表达，而非投影。员工每天使用 8 小时而不视觉疲劳，是第一设计约束。界面文案为简体中文。

## 2. Color Palette & Roles

- **深潭青 Primary（#0F766E）**：主操作色。登录按钮、发送按钮、选中态、链接、侧栏当前项标识。深而不闷，与常见企业默认蓝拉开差异。
- **青玉 Accent（#14B8A6）**：流式生成中的呼吸感点缀——打字机光标、加载指示、Agent 在线状态点。
- **玄墨文本（#0F172A）**：正文与标题文字，接近纯黑但更柔和。
- **云母背景（#F8FAFC）**：应用底色，接近纸面的冷白。
- **薄雾卡片（#FFFFFF）**：卡片、侧栏、输入框底，纯白以与背景形成极浅层次。
- **石墨描边（#E2E8F0）**：hairline 边框与分隔线，1px，替代阴影承担层次。
- **雾灰次级文本（#64748B）**：辅助说明、时间戳、占位符。
- **琥珀警示（#D97706）**：配额提示、次要警告。
- **绯红错误（#DC2626）**：错误消息、失败重试按钮。
- 深色模式：预留 token 语义位（本项目先交付浅色）。

## 3. Typography Rules

- 标题字体：**Montserrat**（几何无衬线，600/700 字重），标题字距略收紧。
- 正文字体：**Inter**（400/500），长文对话场景优先可读性，行高 1.6。
- 中文回退栈：`PingFang SC, Microsoft YaHei, Noto Sans SC`（中文占界面文案主体，拉丁字体仅作用于数字与英文）。
- 层级策略：页面标题 20–24px/600；卡片标题 16px/600；正文 14px/400；辅助 12px/400。对话正文可用 15px 提升阅读舒适度。

## 4. Component Stylings

- **Buttons**：主按钮深潭青底白字，8px 圆角，hover 加深一档；次级按钮白底石墨描边；危险操作绯红描边。无渐变。
- **Cards/Containers**：纯白卡片、8–12px 圆角、1px 石墨描边、无投影或仅 whisper 级弥散阴影（`0 1px 2px rgba(15,23,42,0.05)`）。
- **Inputs/Forms**：白底、1px 石墨描边、8px 圆角、聚焦时描边切换为深潭青并外扩 2px 同色 15% 透明光环。
- **Chat bubbles**：用户消息深潭青底白字（右侧，12px 圆角带一个 4px 小切角）；AI 回复无气泡、白底全宽排版（markdown 正文、代码块浅灰底 `#F1F5F9`），体现"文档感"而非"聊天软件感"。
- **Sidebar**：云母底或纯白底，选中项以深潭青 8% 透明底 + 左侧 3px 实色条标识。

## 5. Layout Principles

- 三栏骨架：左侧窄导航（Agent 列表/历史/管理入口）+ 中间主内容 + 可收起右栏（Agent 详情/参数）。
- 对话页为主战场：输入框常驻底部居中（max-width 760px 正文列），历史消息同列向上滚动。
- Admin 页密度优先：紧凑表格（行高 40px）、批量操作条、克制用色。
- 间距体系 4 的倍数；页面级留白 ≥ 24px；卡片内边距 16–24px。
- 空状态要有引导性：首次进入对话页展示"选择一个 Agent 开始"的卡片式引导。
